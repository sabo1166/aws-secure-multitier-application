How these statuses are computed
  • Completed means every claim a task depends on is Verified in the evidence register, or the document it promises exists.
  • In progress means some evidence exists, or the code is written but the AWS evidence is still missing.
  • Planned means nothing exists yet.
  • Blocked means the task needs a decision that is still open in the decision log, or a claim has failed.
  • A phase is Blocked if any task is, Completed if all are, In progress if any has started, and Planned otherwise.
  • The data is generated by tools/build-roadmap.mjs from docs/project/. tools/check-docs.mjs fails if the page data is stale.
